# data/

Put benchmark files here. Nothing in this directory is shipped.

See [docs/datasets.md](../docs/datasets.md) for download and conversion commands.

```text
data/
  merged_sorted.json          # OmniGUI
  benchmark/                  # OmniGUI screenshots
  screenspot_v2/
  screenspot_pro/
  mmbench_gui/
  android_control/merged_sorted.json
  android_control/images/
  mind2web/mind2web_annots/
  mind2web/ming2web_images/
  mind2web/merged_sorted_{task,website,domain}.json
```
